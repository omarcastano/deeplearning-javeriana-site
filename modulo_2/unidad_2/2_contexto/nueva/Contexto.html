Redes recurrentes

Bienvenidos a la última unidad del curso. Hasta ahora, nuestras redes recibían un dato completo (una imagen, una fila de una tabla) y respondían. Pero muchos datos llegan en orden, uno tras otro: la temperatura de cada hora, las ventas de cada día, los pasajeros de cada jornada, las palabras de una frase. Para entenderlos importa tanto el valor como el momento en que ocurrió. Para este tipo de datos se crearon las redes neuronales recurrentes, redes que leen una secuencia un dato a la vez y recuerdan lo que ya leyeron. Hoy se usan para pronosticar la demanda de energía, el clima o las ventas, para vigilar señales médicas y de máquinas, y estuvieron detrás del reconocimiento de voz y de la traducción automática.

Con el fin de entender a profundidad cómo funcionan estas redes y cómo se usan para pronosticar series de tiempo, los invito a que estudiemos el libro guía del curso: “Hands-On Machine Learning with Scikit-Learn and PyTorch” del autor Aurélien Géron. Para esta unidad, la lectura obligatoria es el capítulo 13, sobre el procesamiento de secuencias con redes recurrentes. El capítulo usa el mismo ejemplo con el que trabajaremos en la Experiencia: los pasajeros diarios del metro de Chicago.
