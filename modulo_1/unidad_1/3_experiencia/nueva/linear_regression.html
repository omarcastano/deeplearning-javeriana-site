Etapa 1 · El punto de partida

Un conjunto de datos

Un problema de aprendizaje supervisado parte de \(N\) ejemplos, cada uno con una entrada y su respuesta correcta. El objetivo es encontrar una función que prediga la respuesta a partir de la entrada.

Conjunto de datos
\[ D = \{(x_i,\, y_i)\}_{i=1}^{N} \]
Entrada

\(x_i\): lo que se le da al modelo.

Etiqueta

\(y_i\): la respuesta correcta que el modelo debe aprender.

Muestra

\((x_i, y_i)\): un ejemplo completo, entrada con su etiqueta.

Cada punto es un ejemplo: una variable de entrada \(x\) y su respuesta \(y\). ¿Ves algún patrón? Hace falta una función que lo describa: el modelo.

Etapa 2 · El modelo

El modelo: una recta con dos parámetros

Para predecir \(y\) a partir de \(x\) se necesita una función. La más simple es una línea recta, y el modelo que la usa se llama regresión lineal:

Modelo de regresión lineal
\[ \hat{y}_i = w_1\,x_i + w_0 \]
\(\hat{y}_i\): predicción para la muestra \(i\) (no el valor real \(y_i\)).
\(x_i\): variable de entrada de la muestra \(i\). Es un dato fijo.
\(w_1\) (pendiente): cuánto sube la recta por cada unidad de \(x\).
\(w_0\) (sesgo): el valor de la recta cuando \(x = 0\).
Ambos son los parámetros: lo que el entrenamiento ajusta.

Al inicio los parámetros se eligen al azar. Calcular \(\hat{y}\) a partir de \(x\) se llama forward. Casi nunca \(\hat{y}\) coincide con \(y\): esa diferencia es el error que se mide a continuación.

Mueve \(w_1\) y \(w_0\) y observa la recta. El punto naranja es el valor real \(y\) de una muestra; el azul, la predicción \(\hat{y}\).
Primera muestra: \(x = 0{,}2739\) · valor real \(y = 1{,}4893\)
\(\text{predicción } \hat{y} = 0{,}00 \cdot 0{,}2739 + 0{,}00 = 0{,}00\)

Etapa 3 · La pérdida

El error de una muestra

El modelo produce una predicción \(\hat{y}_i\) para cada muestra. Para saber qué tan buena es, se compara con la etiqueta real \(y_i\): la diferencia es el error de esa muestra.

Error de una muestra y su cuadrado
\[ e_i = \hat{y}_i - y_i \qquad\qquad e_i^2 = (\hat{y}_i - y_i)^2 \]
\(i\): índice de la muestra, de 1 a \(N\).
\(\hat{y}_i\): predicción del modelo para la muestra \(i\).
\(y_i\): etiqueta real de la muestra \(i\).
\(e_i\): error de la muestra \(i\). Es positivo si el modelo predice de más y negativo si predice de menos.
1 · Predicción

Se calcula \(\hat{y}_i\) con el modelo y los parámetros actuales.

2 · Error

Se resta la etiqueta real. Cuanto más lejos de 0 está \(e_i\), peor es la predicción.

3 · Cuadrado

Se eleva \(e_i\) al cuadrado: el resultado nunca es negativo y los errores grandes pesan más.

\(e_i^2\) mide el error de una muestra. El modelo se evalúa con las \(N\) muestras, así que el siguiente paso es combinar todos estos errores en un solo número.

Etapa 3 · La pérdida

La pérdida: un solo número para todo el conjunto

Para evaluar el modelo con las \(N\) muestras, se promedian sus errores al cuadrado \(e_i^2\). El resultado es la pérdida o función de costo: cuanto menor, mejor el modelo.

Error cuadrático medio (MSE)
\[ L(w_1,w_0)=\frac{1}{N}\sum_{i=1}^{N}\big(w_1\,x_i+w_0-y_i\big)^2 \]

\(\sum\): suma sobre las \(N\) muestras. Cada término es \(e_i^2\), que depende de \(w_1\) y \(w_0\) a través de \(\hat{y}_i\).

Cuadrado

Los errores positivos y negativos no se cancelan, y los errores grandes pesan más.

Promedio

Dividir entre \(N\) hace que la pérdida sea comparable entre conjuntos de distinto tamaño.

Valor de \(L\)

Cerca de 0 indica buenas predicciones. Con datos con ruido el mínimo no es exactamente 0.

Objetivo del entrenamiento: los parámetros que hacen mínima la pérdida
\[ (w_1^{*},\,w_0^{*}) = \arg\min_{w_1,\,w_0} L(w_1,w_0) \]

Etapa 3 · La pérdida

El modelo con n variables de entrada

Ya están el modelo, el error y la pérdida, todos con una sola variable de entrada. Si cada muestra tiene \(n\), solo cambia el modelo. Las etapas siguientes (superficie de pérdida, gradiente, optimizador y ciclo de entrenamiento) funcionan igual. En la sesión se usa \(n = 1\) para poder dibujarlo.

Modelo con varias variables de entrada
\[ \hat{y}_i = w_1\,x_{i,1} + w_2\,x_{i,2} + \cdots + w_n\,x_{i,n} + w_0 \]
\(x_{i,j}\): la variable de entrada \(j\) de la muestra \(i\), con \(j = 1, \dots, n\).
\(w_j\): la pendiente de la variable \(j\), cuánto influye en la predicción.
\(w_0\): el sesgo, igual que en la recta.
Caso particular

Con \(n = 1\) se obtiene la recta \(\hat{y}_i = w_1 x_i + w_0\) que se usa en toda la sesión.

Qué cambia

Hay \(n + 1\) parámetros en lugar de dos: una pendiente \(w_j\) por variable y el sesgo \(w_0\).

Qué no cambia

El error \(e_i\) y la pérdida \(L\) se calculan igual con la nueva \(\hat{y}_i\). El gradiente tiene una parte por parámetro y el optimizador actualiza cada uno con la misma regla.

Etapa 3 · La superficie de pérdida

Entrenar es bajar por un tazón

La pérdida \(L\) es una función de los parámetros y puede graficarse como una superficie. Al ser un promedio de cuadrados, tiene forma de tazón con un único mínimo: entrenar es llegar a su fondo.

Un parámetro: si se fija \(w_0\), \(L\) es una parábola en \(w_1\).
Dos parámetros, vista desde arriba: cada línea une combinaciones con igual pérdida; más cerradas, menor pérdida.

En cada punto solo se conoce hacia dónde baja la pérdida, no el tazón completo. La línea ámbar va de los valores iniciales al mínimo \((w_1^*, w_0^*)\); cómo se da cada paso se explica a continuación.

Etapa 4 · El gradiente

El gradiente: la pendiente de la pérdida

Para bajar por el tazón hay que saber hacia dónde baja la pérdida. Esa información la da el gradiente.

Gradiente de la pérdida
\[ \nabla L \]

En cada punto indica hacia dónde sube la pérdida y qué tan inclinada es. Con un solo parámetro es simplemente la pendiente de la curva.

Signo

Positivo: la pérdida sube al aumentar el parámetro. Negativo: la pérdida baja al aumentarlo.

Tamaño

Grande: pendiente fuerte, lejos del fondo. Cercano a 0: cerca del mínimo.

Prueba: mueve \(w_1\) (con \(w_0\) fijo) y observa la pendiente en ese punto. La flecha verde indica hacia dónde baja la pérdida.

Etapa 5 · El paso de optimización

El optimizador: descenso por gradiente

Falta usar el gradiente para mover los parámetros. Eso lo hace el optimizador. El más simple es el descenso por gradiente: da un paso en la dirección contraria al gradiente.

Actualización de los parámetros
\[ \begin{aligned} w_1 &\leftarrow w_1-\eta\,\nabla_{w_1}L \\ w_0 &\leftarrow w_0-\eta\,\nabla_{w_0}L \end{aligned} \]
\(w_1\), \(w_0\): los parámetros en su valor actual.
\(\nabla_{w_1}L\), \(\nabla_{w_0}L\): la parte del gradiente de cada parámetro: cuánto sube \(L\) al aumentarlo.
\(\eta\) (tasa de aprendizaje): el tamaño del paso.

Se resta porque el gradiente apunta hacia donde la pérdida sube. Otros optimizadores, como Adam, parten del mismo gradiente. Falta ver qué tan grande debe ser \(\eta\).

Cada punto rojo es la posición tras una actualización (\(t\) = 0, 1, 2…). Los pasos se acortan al acercarse al mínimo, porque el gradiente se hace más pequeño.

Etapa 5 · La tasa de aprendizaje

El tamaño del paso lo cambia todo

En la actualización \(w_1 \leftarrow w_1 - \eta\,\nabla_{w_1}L\) (y lo mismo para \(w_0\)), la tasa de aprendizaje \(\eta\) controla qué tan grande es cada paso. Su valor decide si el descenso funciona.

Muy pequeña

Llega, pero tarda

Los pasos son tan cortos que se necesitan muchas iteraciones para acercarse al mínimo.

Adecuada

Converge rápido

Los pasos son grandes al inicio y se acortan solos, porque el gradiente disminuye al acercarse al mínimo.

Muy grande

Diverge

Cada paso se pasa del mínimo más que el anterior, y la pérdida crece en lugar de bajar.

\(\eta\) no se aprende: se elige antes de entrenar (es un hiperparámetro) y suele ajustarse probando varios valores. Con \(\eta\) elegido, ya se puede armar el ciclo completo.

Etapa 6 · El ciclo de entrenamiento

¿Cuándo termina el entrenamiento?

Las iteraciones del ciclo se repiten, así que hay que decidir cuándo detenerse: es el criterio de parada. Hay tres habituales, que también pueden combinarse.

Criterio 1

Máximo de épocas

Una época es una pasada completa por todas las muestras. Se fija cuántas hacer: muy pocas dejan el modelo lejos del mínimo; demasiadas gastan tiempo.

Criterio 2

Gradiente casi cero

Cerca del mínimo el gradiente es muy pequeño. Se detiene cuando su tamaño es menor que un umbral pequeño \(\varepsilon\).

Criterio 3

Pérdida estable

Se vigila \(L\) en cada época y se detiene cuando deja de bajar de forma apreciable.

¿Puede quedarse atascado? En regresión lineal, \(L\) tiene forma de tazón (es convexa) y un único mínimo, así que el descenso siempre llega a él. En modelos más complejos, como las redes neuronales, la superficie puede tener varios mínimos locales y zonas planas, y el resultado depende del punto de partida.

Etapa 7 · Época, batch y minibatch

¿Por qué dividir los datos en grupos?

Hasta ahora, cada iteración calculó el gradiente con las \(N\) muestras. Si \(N\) es muy grande, cada step es lento y costoso. La alternativa es estimarlo con un grupo de \(m\) muestras al azar, llamado minibatch, y actualizar con ese estimado. Este método se llama descenso por gradiente estocástico (SGD).

Etapa 8 · Comparación

Tres tamaños de batch, tres caminos

Ya se sabe cómo se recorren los datos; falta decidir cuántas muestras usar en cada step. Se compara el mismo entrenamiento con tres valores de \(m\).

Mismo modelo, mismo punto de partida y misma \(\eta\). Cada variante usa un tamaño de batch distinto; la pérdida se mide al final de cada época.

Batch completo

Con \(m = N\) hay 1 step por época. Camino suave, pero avanza lento. Útil con pocos datos.

Minibatch

Con \(1 < m < N\) hay \(N/m\) steps por época. Baja rápido y con bastante estabilidad. Es lo más habitual.

Estocástico (un dato a la vez)

Con \(m = 1\) hay \(N\) steps por época. Muchas actualizaciones, pero ruidosas: la pérdida oscila.

Elegir \(m\) es un equilibrio entre costo por step, número de actualizaciones y estabilidad. Cuanto más pequeño es el batch, más ruidoso es el gradiente y suele convenir una \(\eta\) menor.

Cierre · Para pensar

Preguntas para repasar

Explica con tus palabras cada pregunta y luego pulsa Ver respuesta (se abre una a la vez).

  1. ¿Qué pasa con el entrenamiento si la tasa de aprendizaje es demasiado grande, aunque se aumenten las iteraciones?
    Ver respuesta

    Los pasos se pasan del mínimo y el error crece en cada paso (diverge). Más iteraciones no lo corrigen: hay que bajar \(\eta\).

  2. Si los datos son millones, ¿por qué conviene trabajar con minibatches en lugar de todos los datos a la vez?
    Ver respuesta

    Calcular el gradiente con todos los datos en cada paso es muy lento. Con minibatches cada paso es rápido y en cada época se dan muchos más steps.

  3. ¿Por qué la pérdida baja rápido al inicio y luego se aplana?
    Ver respuesta

    Al inicio la pendiente es grande, así que los pasos también lo son. Cerca del mínimo la pendiente es pequeña y los pasos se acortan solos.

  4. ¿Qué se gana y qué se pierde al usar un batch de tamaño uno?
    Ver respuesta

    Se gana: un step muy rápido y muchísimos steps por época. Se pierde: el gradiente es muy ruidoso (la pérdida oscila) y no se aprovecha el cálculo en paralelo de muchos datos.
